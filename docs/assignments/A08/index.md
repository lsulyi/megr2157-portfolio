# A8 – Gear Box

## Objective
- Design a gearbox that can be assembled and disassembled.
- Analyze and size input and output shafts for strength.
- Design journal bearings to support shafts.
- Create a gearbox housing with proper clearance and fastening.
- Use parametric CAD modeling to generate a final design.
- Document calculations, sketches, and lessons learned.

## Input Shaft 
Below are my calculations for the input shaft. I calculated stress to be 1222.96 psi, max stress to be 26,850 psi, and a safety factor of 21.95. This meant that the input shaft is sufficient. I also found power to be .0218 hp, and torque to be 0.46875 in-lbf.

## Lessons Learned 
I learned the most about assemblies in SolidWorks because of this assignment. I had used it previously, but that was with a tutorial video where I just followed the video. This time, it was on my own. I found adding the correct mates fairly tedious, and it is something I need to work on. I believe there was a slight interference error with one of the gears, but I plan to go back and look at it afterwards. Overall, I found the modeling of the gearbox to be enjoyable, and I plan to improve my assembly skills for the future.
